# Alternative text — Turn2Opinion consent page

Every image, icon and graphic on the page has alternative text (read by screen readers, shown if an image can't load). Generated by `npm run alt:report`.

## Images (1)

| File | Alt text | Where |
|---|---|---|
| `public/brand/turn2opinion-logo.webp` | Turn2Opinion.com logo | `src/App.jsx:235` |

Logo note: the Turn2Opinion.com logo (public/brand/turn2opinion-logo.webp/png, made from the logo you supplied; a 1000 px copy is included) is the brand's own. The circular-arrows "2" mark on the phone screen, the receipt printer and the receipt paper is drawn as SVG (src/components/T2OMark.jsx) — decorative there, because the logo itself is labelled. The phone and its mini survey, the stickers, reactions, hearts, chat bubbles, smiley switch knobs and the receipt printer are CSS decoration inside elements marked `aria-hidden`; the phone as a whole is one labelled graphic that announces reading progress.
